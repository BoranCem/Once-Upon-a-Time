# 2D Bar Game

A story-driven 2D bar game developed with Unity. Play as a bartender, interact with customers, prepare cocktails, and discover recipes as you progress through the game.

## Features

- **Story Mode:** Interact with customers through dialogue and progress through different days.
- **Cocktail Mixing:** Create drinks by selecting three ingredients in a specific order.
- **Cocktail Properties:** Each cocktail has sweetness, sourness, bitterness, strength, and freshness values.
- **Cocktail Book:** Discover recipes, browse unlocked cocktails, and read their stories.
- **Rush Mode:** Prepare drinks according to customer requests and try to achieve a high score before time runs out.
- **Audio:** Background music, customer arrival sounds, and cocktail mixing sound effects.
- **Dialogue System:** Dialogue text appears with a typewriter effect.

## Built With

- Unity
- C#
- TextMeshPro

## Getting Started

### Prerequisites

- Unity Hub
- A compatible Unity Editor version

### Installation

1. Clone or download this repository.
2. Open Unity Hub.
3. Select **Add** and choose the project folder.
4. Open the project with a compatible Unity Editor version.
5. Open the `MainMenu` scene and press **Play**.

If the project does not start from the main menu, open the appropriate scene manually in the Unity Editor.

## Game Modes

### Story Mode
Meet customers, follow their conversations, and prepare cocktails as part of the story.

### Rush Mode
Serve customers under time pressure by matching the requested cocktail properties.
